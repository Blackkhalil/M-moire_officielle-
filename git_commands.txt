Commandes Git à exécuter manuellement si nécessaire :

cd c:\wamp64\www\M-moire_officielle-

# Initialiser le dépôt si nécessaire
git init

# Ajouter tous les fichiers
git add -A

# Créer le commit
git commit -m "Ajout choix role inscription + systeme commentaires + corrections suivi soumissions"

# Vérifier le commit
git log --oneline -1

# Si vous avez un dépôt distant configuré, pousser :
git remote -v
git push origin main
# ou
git push origin master
