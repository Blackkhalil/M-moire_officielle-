═══════════════════════════════════════════════════════════════════════════════
                        INTERACTIONS CLÉS
═══════════════════════════════════════════════════════════════════════════════

FRONTEND ──► BACKEND
   • Les pages PHP (htdocs/*.php) appellent les scripts backend (app/*.php)
   • Utilisation de require_once pour charger les modules
   • Passage de données via $_POST, $_GET, $_SESSION

FRONTEND ──► API REST
   • JavaScript (AJAX/Fetch) communique avec api/notifications.php
   • Échange de données en format JSON
   • Requêtes asynchrones (pas de rechargement de page)

BACKEND ──► BASE DE DONNÉES
   • Utilisation de PDO (PHP Data Objects) pour la connexion
   • Requêtes préparées pour la sécurité (anti-injection SQL)
   • Transactions pour les opérations critiques

BACKEND ──► FICHIERS
   • Upload de fichiers dans uploads/rapports/ et uploads/presentations/
   • Noms de fichiers uniques (timestamp + ID projet)
   • Protection des dossiers avec index.php
