COMMANDES GIT A EXECUTER :
---------------------------

1. Ouvrir un terminal (PowerShell ou CMD) dans le dossier du projet :
   cd c:\wamp64\www\M-moire_officielle-

2. Vérifier l'état du dépôt :
   git status

3. Ajouter tous les fichiers modifiés :
   git add -A

4. Créer le commit :
   git commit -m "Ajout choix role inscription + systeme commentaires + corrections suivi soumissions"

5. Si vous avez un dépôt distant configuré, pousser les modifications :
   git push origin main
   (ou git push origin master selon votre branche)

ALTERNATIVE - UTILISER LE SCRIPT :
-----------------------------------
Double-cliquez sur le fichier COMMIT_GIT.bat pour exécuter automatiquement
les commandes git avec des instructions interactives.
